# An optional public interaction inbox reuses relay admission, not the outbox

> **Status:** concept accepted for #164; implementation is separate from the nsite first cut in ADR 0013. No importer runs merely because nsite hosting is selected.

S2 visitors write to foreign relays; those interactions never reach Studio through the send-only outbox (ADR 0009). A separate opt-in **interaction import** brings signed interactions with locally known videos into the instance's existing relay so the same Studio catalog and local moderation apply. It is not a mirror of other creators' content and cannot moderate foreign copies.

**Read only explicit public interaction sources.** Import is disabled by default and runs only in public reach, independent of site hosting or identity. Sources are the deduplicated public config `interactionRelays` and public mirror relays, excluding the instance itself. Never discover a remote source from an event's relay hint or a creator's arbitrary kind 10002; this avoids event-controlled outbound connections. Switching private or disabling import cancels reads; persisted cursors stay for a later resume.

**Only existing local scope is eligible.** Query comments (1111), legacy replies (1), reactions (7) and reports (1984) referencing locally known video ids and coordinates through `e`/`E`/`a`/`A`; include superseded ids from `video_version`. Resolve reply chains against accepted local interactions, importing parents before children. Reports may additionally target current allowed writers through `p` and video media hashes through `x`, as ADR 0011 permits. Import kind 5 only for deletions targeting locally accepted interactions; unknown ids, foreign scope, invalid signatures and author-mismatched deletions gain no rights. Displayed creators that are not allowed writers do not expand the inbox.

**Admission remains one authority.** Feed candidates into the same signature, timestamp, message-size, scope and ownership checks as incoming visitor events (ADR 0006/0011). Mark imported events as received copies, so even an allowed writer's imported event does not enqueue outgoing mirrors. Persist accepted events and update subscriptions using the existing relay path; rejected candidates are not inserted into a second event store. Deduplication is by event id. Repeated scans and two importing instances cannot create an outbox loop.

**Periodic catch-up before live subscriptions.** A cancellable worker scans once per minute with bounded relay concurrency, filter batches and response bytes/timeouts; each request ends at EOSE or a visible timeout. First enable starts with the previous seven days; later scans resume a durable per-relay checkpoint with an overlap for late arrivals and inclusive timestamp boundaries. Advance only after a complete scan and durable admission; reconnecting or restarting replays safely. If a result cap prevents covering a timestamp, retain the checkpoint and expose the incomplete scan instead of skipping same-second events. Reply discovery is bounded and unresolved chains are retried in later scans. Large/older history is not silently promised; a separate manual bounded backfill can be added when requested. Live subscriptions are unnecessary for the minute-scale Studio use case.

**Zaps require an explicit admission extension.** ADR 0006 currently excludes kind 9735. Do not import receipts as generic writer events or accept arbitrary signed receipts as proof of payment. A separate slice verifies NIP-57 request/receipt relationships, target video and recipient, the authorized LNURL provider key, amount and invoice before allowing receipts through the common visitor admission path. Network verification uses recipient-controlled LNURL configuration, not arbitrary receipt URLs, and retains trust-boundary protections. Until that slice ships, import explicitly reports that zaps are unsupported rather than counting unverified payments.

**Studio exposes consent and progress.** The Advanced page offers opt-in, lists actual sources, last successful scan, catch-up/pending/error counts and a retry. Explain that remote relays see the instance IP and requested local video ids, and that local mute/hide/delete actions affect only the local copy. Switching private pauses imports even if mirrors remain configured. No new moderation model or gateway erasure promise is introduced.

This amends ADR 0009's “nothing comes in” only for the separately enabled inbox. The outbox stays send-only, and ADR 0013's accepted absence of visitor interactions in S2 remains true until the follow-up implementation is enabled.
